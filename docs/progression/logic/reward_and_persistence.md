# 奖励与存档逻辑

状态：已实现。

- `RewardService` 生成奖励；`RewardApplyService` 应用奖励。
- 奖励使用 Schema v1 的 `schema_version`、`source`、`target_type` 和 `effect` 字段；旧的 `kind`、`value`、`item_id`、`skill_id` 字段保留兼容，`RunStateSerializer` 读取旧 active run 时会补齐新字段。
- 正式战斗按遭遇等级发放塔币：普通/精英/Boss 使用有效塔层的 `1x/3x/10x` 倍率；一次性物品基础掉落概率为 `20%`，装备掉落概率为普通 `10%`、精英 `50%`、Boss `100%`。
- Boss 的塔内技能奖励只从技能槽 `3/4` 选择，并可额外提供塔内被动技能；塔内奖励目标同时包含当前塔内装备和技能。
- `SaveProfile` 保存永久队伍、装备、技能、教程完成、塔币、血瓶等级/剩余次数/种子、图鉴记录和 NPC 解锁 ID。
- NPC 定义位于 `DataCatalog.NPCS`；首次击败正式第 1/3/5 层 Boss 分别解锁商人、铁匠、法师，并写入 Profile。商人提供塔内一次性物品，铁匠提供永久装备，法师提供永久技能。
- 正式第 1/3/5 层分别累计遇到 9/7/5 个群落后，解锁对应 NPC 的升级功能；活动存档使用二级数组保存每一层遇到的每一个群落，升级数量只统计当前楼层记录。
- 高塔难度由 `0` 到 `+6` 共七档；每档只在首次通关时发放一个种子，种子将血瓶使用次数从 `3` 次逐步提升到 `10` 次。首次完成第 7 层还会解锁首个被动槽和被动技能。
- `RunStateSerializer` 保存 active run：楼层、战斗序号、群落历史、玩家/敌人状态、资源、冷却、状态卡、背包、装备和技能。
- 离塔写入永久 Profile 时清空塔内装备、塔内一次性物品、塔内技能、塔内被动和局内附着，避免塔内成长带出塔外。
- 存档保存稳定 ID，不保存 Mod 绝对路径；未来 Mod 缺失时由迁移/兼容策略处理。
