# 战斗回合详述

状态：已实现。

## 战斗开始

创建玩家、敌人和盟友 Combatant；应用装备、被动能力、群落能力、塔层倍率和战前状态；按敏捷确定顺序，处理 `first_strike`。

## 玩家行动

- 普攻：按武器攻击段数产生一个或多个命中事件；每段分别处理状态、格挡、闪避和伤害。
- 防御：根据基础格挡和技能/状态倍率获得格挡。
- 躲避：获得闪避层；下一次符合条件的攻击消耗闪避层。
- 技能：检查槽位、解锁、资源、冷却和目标，再按 `actions` 顺序执行。

## 敌方行动

`EnemyActionRules` 根据被动能力、行为权重、生命/状态和可用技能决定行动；普通攻击、技能和召唤/裂变均通过统一行动与状态入口。

## 结算

伤害顺序包括原始伤害、护甲/防御、格挡/闪避、状态修正、生命变化、命中触发和击杀触发。战斗胜负后由 `RewardService` 和 `PlaySession` 处理奖励、存档和下一场。

特殊规则（腐败、尖牙减甲、裂变、召唤、场地效果）必须作为能力/状态数据或 `EnemyActionRules` 的集中行为，不得散落在 UI。
