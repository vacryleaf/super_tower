# 扩展边界

状态：设计已确认待实现。

## 允许扩展

- 新增技能/武器/物品/怪物数据文件。
- 新增状态、触发器和行动类型，但必须先登记 Schema 与解释器支持。
- 新增图鉴字段、翻译键和 UI 标签，不改变运行时核心服务的职责。

## 禁止扩展方式

- Mod 直接调用 `BattleService` 私有方法。
- 在 UI、图鉴或单个武器条目中复制伤害结算。
- 用同名 ID 覆盖原版内容。
- 把敌人行为判断散落到 `BattleService`；应放在 `enemy_action_rules.gd`。
- 恢复模拟战斗路径。

## 兼容边界

Save/Profile 只保存稳定 ID 和必要的规范化快照；加载时按 `api_version`、迁移表和缺失内容策略处理，不能把绝对文件路径写入存档。
